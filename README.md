# Productivity Pilot

AI Productivity Assistant

Create an AI-powered productivity assistant with three core features:

Smart Email Generator

Generate professional, personalized emails from short user instructions.

Support professional, friendly, concise, persuasive, and formal tones.

Automatically suggest a subject line.

Allow users to edit, regenerate, copy, and customize emails.

Improve grammar, clarity, and structure while preserving the user's intent.

Meeting Notes Summarizer

Accept meeting transcripts, uploaded notes, or pasted text.

Generate concise summaries of important discussion points.

Identify decisions, key topics, questions, and unresolved issues.

Extract action items, owners, and deadlines when explicitly mentioned.

Provide both quick and detailed summaries.

AI Task Planner

Convert goals, meeting action items, or natural-language instructions into actionable tasks.

Break large goals into smaller subtasks.

Assign priorities, deadlines, estimated effort, and suggested order.

Detect dependencies between tasks.

Generate daily or weekly plans based on deadlines and priorities.

Allow users to complete, edit, reschedule, or regenerate tasks.

Authentication

Do not include authentication or user accounts.

The application should open directly to the main dashboard without:

Login

Sign-up

Password reset

User profiles

Authentication screens

Social login

Account creation

All features should be immediately accessible without requiring the user to authenticate.

User Interface

Create a clean, modern, responsive SaaS-style dashboard with three primary sections:

Emails

Meeting Notes

Tasks

Use natural-language input so users can interact with the AI without complicated forms.

The application should include polished loading states, empty states, error handling, editable AI results, copy buttons, regeneration controls, and responsive layouts.

Do not add any authentication-related functionality anywhere in the application.
